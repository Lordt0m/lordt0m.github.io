Implementation and scope

Order integrity
Server-owned menu prices, integer naira amounts and a database constraint on request keys.
Safe updates
Explicit status transitions and conditional revision updates, recorded with transactional history.
Restaurant boundaries
Browser-session workspaces and server-filtered kitchen queries. The role switcher is a demo feature, not production login.
Outside this concept
Payments, delivery, production authentication and native mobile builds. The current demo uses SQLite and temporary storage.
